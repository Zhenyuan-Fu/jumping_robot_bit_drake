BIT JUMPING ROBOT
======================


This repository contains code for the simulation and control of BIT jumping robot using [Drake](https://drake.mit.edu).


Firstly, to install Drake and its python binding
------------------------
- [Drake installation](https://drake.mit.edu/installation.html)

Secondly, to install Russ's tutorial 
------------------------
- [Underactuated installation](https://github.com/RussTedrake/underactuated)

- [RussTedrake's course notes](http://underactuated.mit.edu/)


Firstly, to install Pinocchio and its python binding
------------------------
- [Pinocchio installation](https://stack-of-tasks.github.io/pinocchio/download.html)


## Dependencies

- [Drake](https://drake.mit.edu), make sure your python binding can be used
- [Pinocchio](https://stack-of-tasks.github.io/pinocchio/download.html), make sure your python binding can be used
- [Eigen](http://eigen.tuxfamily.org/)
- [Ipopt](https://projects.coin-or.org/Ipopt)
- [ifopt](https://github.com/ethz-adrl/ifopt)
- [CMake](https://cmake.org/cmake/help/v3.0/)
- [Numpy](https://numpy.org)
- [LCM](https://lcm-proj.github.io/) (optional) 

## LCM and TOWR Installation (optional)

For this simulation, the two package are not necessary. If you want to try TOWR planner and LCM, you can intstall them. 

Clone this repository: `git clone https://github.com/.git`

Compile C\+\+ code (includes TOWR and custom LCM bindings for interface with drake):
```
mkdir -p build
cd build
cmake ..
make
```

For the jumping models:
-------------------------------------------
There are three models provided in dir:
 
- The first model provides the raw urdf and raw meshes which are generated by solidworks automatically (model in`./raw_model`).
 
- The second one is for drake. I add some additional sentences for drake actuators and self-collision, 
you can compare the urdf with the raw one. Also, the mesh format is changed from '.stl' to '.obj' (model in`./jumping_robot_bit`).

- The third one is for pinocchio. The urdf is almost same as it in drake urdf, and I just use the urdf (urdf in`./jumping_robot_bit/urdf/jumping_robot_bit_pin.urdf`).. 

To check your file path of the urdf and meshes
------------------------

Check the path of the robot model, then change it in "simulate_jump.py" and "simulate_raise_foot.py", make sure to load the bit jumping robot model correctly. 
For drake, check `robot_description_path_drake`
For pinocchio, check `robot_urdf_path_pin`.

## Usage

### 1. Move to desired CoM pos, then jump
- Start the drake visualizer `bazel-bin/tools/drake_visualizer`.

- Edit "./clf_ctl/simulate_jump.py", set `planning_method` as `opt_traj_matlab`, then set `control_method` as `COMID`

- Run the simulation script `./clf_ctl/simulate_jump.py`.

### 2. Stand, then raise leg, then squat
- Start the drake visualizer `bazel-bin/tools/drake_visualizer`.

- Edit "./clf_ctl/simulate_raise_foot.py", set `planning_method` as `basic`, then set `control_method` as `ID`

- Run the simulation script `./clf_ctl/simulate_raise_foot.py`.
